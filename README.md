# 陪伴型應用 - Companion App

一個以陪伴和日常節奏為中心的應用程式，旨在創造溫和的「有人陪伴你」的存在感。

## ✨ 核心概念

螢幕中央的小植物般的角色作為安靜的陪伴者，會隨著天氣和使用情境逐漸成長。這個角色作為視覺和情感焦點，所有其他元素都從屬於它。

## 🎨 設計特色

- **極簡美學**：淺米色/淡奶油色背景，深灰色低飽和度按鈕
- **平靜氛圍**：優先創造短暫停頓和溫柔關懷的數位空間
- **呼吸感**：充足的空白空間，避免資訊密度過高
- **時間感知**：根據時段自動調整光照和背景色調

## 🚀 快速開始

### 添加 3D 模型

**方法 1：使用 public 文件夾**
```bash
# 在項目根目錄創建 public 文件夾
mkdir public

# 將你的 plant.glb 放入 public 文件夾
cp path/to/your/plant.glb public/
```

**方法 2：瀏覽器上傳**
1. 打開應用
2. 點擊中間的閃光佔位符
3. 選擇你的 `.glb` 文件
4. 模型立即加載

### 開發

```bash
# 安裝依賴
pnpm install

# 啟動開發服務器
pnpm run dev
```

## 📱 功能特色

### 3D 角色渲染
- 支持 GLB 格式 3D 模型
- 滑鼠拖曳旋轉
- 自動縮放適配
- 輕微漂浮動畫
- 隨時更換模型

### 時間自適應
- **早晨 (5-10點)**：淺藍背景，柔和晨光
- **白天 (10-16點)**：米色背景，明亮日光
- **傍晚 (16-19點)**：暖橙背景，溫暖晚霞
- **夜晚 (19-5點)**：深藍背景，柔和月光

### 界面組件
- iPhone 風格圓角框架 (9:19.5)
- 頂部：時間、日期、天氣
- 中間：3D 角色展示區
- 底部：液態風格導航欄
- 安全區域支持（劉海屏適配）

## 🛠️ 技術棧

- React 18.3
- Three.js（3D 渲染）
- Motion/Framer Motion（動畫）
- Tailwind CSS 4.1
- Lucide React（圖標）
- Vite（構建工具）

## 🎯 設計理念

這個應用不追求效率或資訊密度，而是創造一個讓人願意每日開啟的數位空間——一個與陪伴者的日常儀式，具有極簡、平靜的感覺和充足的呼吸空間。

---

**注意**：此應用專注於陪伴感，角色不用於對話或任務，而是作為溫和的存在。
