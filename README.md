# PlanTalk：智慧植物管家系統 (AI Plant Care System)

PlanTalk 是一款結合 **IoT 物聯網數據監測** 與 **Generative AI (Gemini 2.5 Flash)** 的全方位植物照護方案。它能讀懂植物的需求，透過數據與視覺診斷，將複雜的養護知識轉化為直覺、溫暖的對話體驗。

---

## 🌟 核心創新：當 AI 遇見 IoT

PlanTalk 的核心價值在於讓 AI 「讀懂」了物理數據。傳統 App 僅能顯示濕度百分比，而 PlanTalk 能結合植物品種特性與即時環境數據，判斷出「這不是缺水，而是根部缺氧」等深層問題，實現真正的 **AIoT (AI + IoT) 智慧養護**。

## ✨ 核心功能

### 1. 智慧視覺診斷 (AI Vision Diagnosis)
- **品種辨識**：拍攝照片即可自動識別植物種類。
- **病蟲害掃描**：分析葉片細微特徵，診斷潛在威脅（如白粉病、昆蟲等）。
- **救治方案**：提供具體的物理、生物及化學防治建議。

### 2. 深度 AI 養護報告
- **五大維度分析**：涵蓋植物現狀、水分管理、光照環境、專業處方及專家小叮嚀。
- **數據聯動**：結合感測器回傳的即時數據（如土壤濕度 100%），提供精準的警示與調整建議。
- **可摺疊 UI 設計**：優化資訊密度，讓使用者一眼掌握重點，點擊展開深度內容。

### 3. AI 擬人化對話介面
- **專業植物學家**：內建精煉、專業的 AI 人設，隨時回答養護問題。
- **即時數據查詢**：使用者可透過對話直接查詢特定植物的健康度與環境數值。

### 4. 環境感知與自動化
- **天氣連動**：根據當前氣溫、氣候自動調整建議的澆水與日照計畫。
- **背景同步**：AI 分析結果會自動同步至植物卡片，不干擾使用者流程。

## 🛠️ 技術棧

- **前端框架**：React 18.3 + Vite
- **AI 大腦**：Google Gemini 2.5 Flash API
- **3D 渲染**：Three.js / React Three Fiber (用於展示植物模型)
- **樣式引擎**：Tailwind CSS 4.0
- **數據同步**：自建 Vite Middleware API 中間層

## 🚀 快速開始

### 1. 環境設定
在根目錄創建 `.env` 檔案並加入您的 API 金鑰：
```env
GEMINI_API_KEY=您的_Gemini_API_Key
```

### 2. 安裝與執行
```bash
# 安裝依賴
npm install

# 啟動開發伺服器
npm run dev
```
